# הנחיות להנהלת ה-AI של נויה במתנה
כל קובץ כאן הוא "תיאור תפקיד" של מנהל, של מנכ״ל ה-AI או של דירקטור. השרת קורא אותו בכל ריצה.
אפשר לשנות כאן נוסח, דגשים וסוכנים – השינוי נשמר בהיסטוריה של הקוד וחל מהריצה הבאה.
הכללים המחייבים (רק ממליצים, אישור של משה לכל פעולה, בלי להמציא נתונים) נמצאים בקוד ולא ניתנים לעקיפה מכאן.
